# Month-end close (small business)

## Workflow
1. Ask four questions: business type (service, product/e-commerce, both), accounting tool (spreadsheet, QuickBooks, Xero, Wave, other), whether they have employees/contractors, and whether they collect sales tax.
2. Build the checklist from `reference/checklist.md`, keeping only relevant items, in order. Present it as a numbered list with a time estimate per item.
3. Work through it with the user one item at a time when asked. For data tasks, use the other skills in this pack if installed: bank-statement-categorizer → books-reconciler → ar-aging-report → cash-flow-forecast → tax-set-aside-tracker.
4. Finish with a short close summary: what was done, open items, figures to review next month.

Never sign off figures as correct; the user (or their accountant) approves the close.
